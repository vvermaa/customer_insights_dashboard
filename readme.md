# Customer Insights Dashboard

## Overview

This project is an interactive dashboard built using Python, SQL, and Streamlit to analyze sales data. It provides meaningful insights into sales performance through visualizations and key metrics.

## Live App

You can access the deployed dashboard here:
https://customerinsightsdashboard-e34kzytnr5dm47lbxou2qg.streamlit.app

## Features

* KPI metrics (Total Sales, Orders, Average Sales)
* Sales trend analysis
* Top-performing cities and regions
* Sales distribution insights
* Dynamic query system based on user input

## Tech Stack

* Python
* SQLite
* Streamlit

## How to Run Locally

1. Clone the repository
2. Install dependencies:

   ```
   pip install -r requirements.txt
   ```
3. Run the app:

   ```
   streamlit run app.py
   ```
