# Customer Insights Dashboard

## Overview
This project is an interactive dashboard built using Python, SQL, and Streamlit to analyze sales data.

## Features
- KPI metrics (Total Sales, Orders, Avg Sales)
- Sales trend analysis
- Top cities and regions
- Sales distribution insights
- Dynamic query system (user input)

## Tech Stack
- Python
- SQLite
- Streamlit

## How to Run
streamlit run app.py
